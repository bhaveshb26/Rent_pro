# 🏠 RentPro – Rental Property Management Platform

A web-based rental property platform designed to simplify property discovery, rental management, and the connection between property owners and tenants.

## 🌐 Live Demo

**[Visit RentPro](https://property-dekho-frontend.onrender.com/)**

## 📌 Project Overview

RentPro is a rental property platform that provides a digital space for users to explore rental properties and manage property-related activities. The project aims to make the rental process more convenient, accessible, and user-friendly.

## ✨ Key Features

- Rental property platform with a user-friendly interface.
- Property discovery and browsing.
- Digital property management.
- Easy access to rental information.
- Responsive web interface.

## 🛠️ Technologies Used

- Frontend: Add the actual frontend framework and languages.
- Backend: Python
- Database: Supabase
- Deployment: Vercel and Render
